# 🚀 Модуль 0 · Начало

Этот модуль нужен тем, кто ещё ничего не ставил и не настраивал.
Запускаете компьютер → Открываете Colab → Пробуете взаимодейстовать с AI через код.

Задача простая: увидеть, что AI — это не магия, а обычный инженерный инструмент.

## 🎯 Что делаем?

- отправите первый запрос к AI через API
- сделаете помощника, который отвечает по вашему файлу
- проанализируете таблицу и получите выводы
- научитесь задавать вопросы так, чтобы AI реально помогал

## 📂 Лабораторные

### [0.1 Первый запрос к AI](lab-01/README.md)

**Что делаем:**
Отправляем запрос через API и получаем ответ.

**Зачем:**
Понимание, что AI — это просто HTTP-запрос + текст.

**Результат:**
Рабочий скрипт в Colab, который отвечает на ваши вопросы.

### 0.2 AI-помощник по вашему файлу

**Что делаем:**
Загружаем PDF / txt / doc → AI отвечает по содержимому.

**Что внутри:**
Простейший RAG в ~30 строк.

**Результат:**
Помощник для инструкций, конспектов, договоров.

### [0.3 Prompt engineering](lab-03/README.md)

**Что делаем:**
Учимся задавать вопросы так, чтобы получать нормальные ответы.

**Управление ответами через:**
- роль
- структура запроса
- примеры
- проверка ответа

**Результат:**
Вы понимаете, как управлять AI.
